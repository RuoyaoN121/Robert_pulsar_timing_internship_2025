# Pulsar-timing internship archive

Curated code, notebooks, analysis products, and the final internship report from work on pulsar timing arrays and gravitational-wave-background searches.

## Contents

- `code/` — analysis and batch-job scripts collected from the internship workspace.
- `notebooks/` — exploratory and analysis notebooks, including the OzGrav parameter-estimation notebook.
- `report/` — the final report source, PDF, and figures.
- `results/tables/` — compact CSV summaries and comparison tables.
- `results/figures/` — corner, gamma, dispersion-measure, and optimal-statistic plots.
- `ozgrav/` — the retained environment specification associated with the OzGrav work.

## Reproducibility notes

Several notebooks and cluster scripts contain paths for the OzSTAR/Fred environment. Update those paths before running elsewhere. The repository contains selected summaries and figures rather than the raw timing data, sampler chains, or cluster logs.

The report discusses work performed with collaborators and external software. Please preserve the original acknowledgements and cite the relevant software and datasets when reusing the material.

## Excluded from this public archive

Personal visa, workplace-training, scholarship, and rental documents; third-party papers and books; raw FITS/timing data; duplicate ZIP archives; machine-generated logs and LaTeX build files; and large sampler chains were intentionally left out.
